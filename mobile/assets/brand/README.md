# Addy AI local brand assets

Geometric A/play mark created in this workspace using the existing #00c2a8
accent and #0e0e11 background. No stock image or font is embedded.
`icon.svg` is the editable vector source. The matching PNGs are rendered by
`mobile/scripts/make-brand-assets.py` with Pillow: icon is opaque RGB;
adaptive and splash foregrounds have transparency. All are 1024 × 1024.

Expo uses these in app.json. Local icon inspection and Expo introspection passed.
Final launcher masks, native splash sizing and release-binary appearance still
need device acceptance. This does not establish trademark availability or legal
clearance. Do not describe it as an approved registered brand.
